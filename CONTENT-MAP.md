# Где что лежит — карта репозитория Web_Playdisplay

Составлено 27.07.2026. Проверено по факту: файлы на диске, ветки git, история, живая страница.

## Короткий ответ

**Сайту нужна только папка `site/`** (136 МБ, 284 файла) — она самодостаточна.
Плюс три служебных файла в корне: `build_seo.py`, `download_assets.sh`, `CLAUDE.md`.

**Всё остальное в папке — 1.1 ГБ — это либо прошлые поколения сайта, либо копии `site/`, либо рабочие материалы.** Ни одна строка из них на сайт не попадает.

## 1. Три поколения сайта живут рядом

`about.html`, `contact.html`, `projects.html` — трёхстрочные редиректы на старый корневой `index.html`. К `site/` отношения не имеют.

## 3. Рабочие материалы — не исходники сайта, около 570 МБ

Уже перечислены в `.gitignore`, но лежат в дереве проекта и создают ощущение хаоса.

- `videos/` — 273 МБ, мастера роликов (на сайте раздаются сжатые копии из `site/videos/`)
- `concepts raw/` — 153 МБ, сырьё концепций (`base`, `prod`, `prod_BACKUP_BEFORE_FIX`, `ready unsorted`, `text`)
- `picture converter/` — 84 МБ, инструмент обработки картинок (несколько версий подряд + zip'и)
- `remade/` — 62 МБ, перерисованные png
- `pdf-slides-extractor/` — 60 КБ, инструмент
- `АМГ-окна — Предложение по MVP.docx`, `Анализ тех.регламента.docx` — **вообще другой проект**, случайно попали сюда

## 4. Ветки: шесть, нужных две

| Ветка | Последний коммит | Что это |
|---|---|---|
| `hybrid-v8` | 27.07 | **актуальная работа.** Содержит все коммиты `proto-3d` |
| `gh-pages` | 27.07 | **то, что реально раздаётся.** Сейчас отстаёт на один коммит (Атлас не задеплоен) |
| `proto-3d` | 22.07 | отстала на 49 коммитов, целиком входит в `hybrid-v8`. Но именно на неё ссылается `CLAUDE.md` и на неё триггерится workflow |
| `gh-pages-ready` | 22.07 | отстала на 25 коммитов, мусор |
| `gh-pages-new` | 22.07 | отстала на 25 коммитов, мусор |
| `master` | 04.07 | старый сайт «Бренд-платформа 2026» |

Отдельно: `origin/HEAD → origin/main`, а `main` содержит один коммит «Initial commit». Поэтому GitHub по умолчанию открывает пустую ветку — это главная причина ощущения «непонятно, где сайт».

## 5. Два конкурирующих деплоя — и работает ни один автоматически

- `.github/workflows/deploy-pages.yml` триггерится на пуш в **`proto-3d`** и требует `Settings → Pages → Source: GitHub Actions`.
- Фактически Pages раздаёт **ветку `gh-pages`** — проверено: живая страница https://sudarikovandrey.github.io/playdisplay_web/ побайтово совпадает с `gh-pages:index.html`.
- Работа идёт в **`hybrid-v8`**.

Итог: пуш рабочей ветки не деплоит ничего, `gh-pages` вы собираете руками. Отсюда постоянная неясность «что сейчас на сайте».

## 7. `CLAUDE.md` устарел и вводит в заблуждение

Написано «рабочая ветка **proto-3d**» — работа идёт в `hybrid-v8`. Написано «gh-pages — единственный канал деплоя», при этом workflow жив и слушает `proto-3d`. Это надо привести в соответствие с тем, что будет решено.
