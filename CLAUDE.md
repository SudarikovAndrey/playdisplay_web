# PLAYDISPLAY — паспорт проекта (для Claude)

Сайт студии интерактивного опыта PlayDisplay. Язык: русский. Владелец: Андрей Судариков.

## Структура папки
Полная карта — в `CONTENT-MAP.md`. Коротко: в репозитории **только текущий сайт**.

```
site/                 ← сайт целиком, единственный источник правды. Самодостаточен: ссылок за свои пределы не имеет
build_seo.py          ← генератор /work/<slug>/, sitemap, robots, llms, SEO-блока главной
download_assets.sh    ← докачка картинок проектов в site/assets/work/
CLAUDE.md  README.md  CONTENT-MAP.md
_ARCHIVE/             ← вне git: прошлые поколения сайта, слепки site/, сырьё. См. _ARCHIVE/README.md
```

Прошлые поколения (бренд-платформа 2026 в корне, 3D-прототип в `dist/` и `proto 3d/`) выведены из отслеживания 27.07.2026 и лежат в `_ARCHIVE/`. Точка возврата — тег `archive/before-cleanup`.

## Деплой
- Рабочая ветка: **hybrid-v8**. Все коммиты `proto-3d` в неё входят, сама `proto-3d` отстала и не используется.
- GitHub Pages фактически раздаёт ветку **gh-pages** (root) — проверено по живой странице. После правок в site/ пересобрать:
  содержимое = `git archive hybrid-v8 site | tar -x --strip-components=1` + `.nojekyll`, новый коммит поверх текущей gh-pages (fast-forward, без force).
- Пуш делает Андрей сам: `git push origin hybrid-v8 gh-pages` (у песочницы нет git-кредов).
- Превью: https://sudarikovandrey.github.io/playdisplay_web/  Боевой домен (в SEO/canonical): https://playdisplay.com
- **Открытый вопрос:** `.github/workflows/deploy-pages.yml` триггерится на пуш в `proto-3d` и требует `Settings → Pages → Source: GitHub Actions`. Сейчас это не совпадает ни с рабочей веткой, ни с реальным каналом раздачи, поэтому автодеплой не срабатывает и gh-pages собирается руками. Решение — либо перевести workflow на рабочую ветку, либо удалить workflow. Пока не решено, воркфлоу не трогать.
- `origin/HEAD` смотрит на `main`, где лежит один «Initial commit» — поэтому GitHub по умолчанию открывает пустую ветку. Ветки `master`, `gh-pages-new`, `gh-pages-ready` — старьё, к работе отношения не имеют.
- Локальный тест: сервер в песочнице умирает между вызовами bash; тестировать на живом gh-pages или через file-инструменты.
- Песочница иногда оставляет `.git/*.lock` после своих коммитов; если git ругается «Another git process» — снять `.git/HEAD.lock`, `.git/index.lock`, `.git/objects/maintenance.lock`.

## Ключевые файлы
- `site/index.html` — весь лендинг-SPA: стили, CASES (15 проектов), сетка Work, кейс-вьюер (#viewer), WebGL-движок переходов FlyGL, роутинг (#work, #/work/<slug>).
- `site/hero-scene.html` — 3D hero (Three.js r128, облако точек), встраивается iframe'ом. Свой мобильный профиль настроек (localStorage `pd_proto_settings_m`), панель настроек по ссылке `?cam=1`.
- `site/data/projects.json` — весь контент кейсов (goal/solution/flow-блоки: h/p/steps/notes/stats/img/yt/vimeo). Вьюер строит страницы из него.
- `build_seo.py` — генерит статические `/work/<slug>/index.html`, sitemap.xml, robots.txt, llms.txt и SEO-блок главной (между маркерами `<!--SEO-->…<!--/SEO-->`). Требует /tmp/cases.json (извлекается из CASES). После изменения структуры/контента — перегенерить.
- `download_assets.sh` — докачка картинок проектов; сжатые копии уже в site/assets/work/. Мастера роликов — в `_ARCHIVE/4 - рабочие материалы/videos/`, сжатые ролики — `site/videos/`.
- `site/data/atlas.json` — Атлас: 90 карточек в шести типах (Концепт, Принцип, Технология, Наблюдение, Приём, Исследование). Подписи фильтра во множественном числе лежат в `catLabels`, поле `cat` у карточки — в единственном (это бейдж). Карточка с `principle` + `examples` открывается в разбор, без них живёт как тезис в сетке (класс `.thesis`, клик не навешивается).
- `site/data/concepts.json` — библиотека авторских концепций (раздел #concepts).

## Что отстроено и НЕ ломать при пересборке
- **FlyGL** (site/index.html): WebGL-переход в кейс и обратно. Влёт: прямоугольная волна растворения от карточки с искрами по фронту, пиксельные частицы с motion-стрейком, морфинг обложки в кадр, сборка страницы (кадр+тексты) из объёмного облака, перекраска зерна живым видео. Вылет: растворение страницы без видимого фронта, финальная волна сходится и «упирается» в карточку-цель, интерьер открыт заранее, фиксация-свечение контура + искры на периметре. Отладка: `?flyslow` (×3 медленнее), `window.__flyK=0.5` (заморозка фазы). Фолбэк без WebGL — быстрый фейд. Слабое железо/мобила — реже сетка частиц.
- Ховер карточек: пыль-магнит с соседних обложек (canvas #cards-fx). На мобиле карточки сразу цветные (без ховера).
- Hero: постоянная связка postMessage лендинг↔iframe (pdVisible, pdMeta, pdPlay, pdScroll, pdRotate, pdTapPlay, pdReady, pdGame, pdCam). Тёмный лоадер с белым лого; верхняя панель выезжает по pdReady. Кликабельный логотип → верх страницы. Портрет: FOV авто-подстраивается (portraitFitFov), cover не зумится; тап = play/стоп.
- Кейс-вьюер: медиа (локальное видео/встройки/картинки), плашки-меты, статы, flow-блоки с каскадным появлением (.settled), галереи-листалки, «следующий проект», lightbox.
- Мобильные фиксы: без бокового скролла, user-select off в hero, cursor:none только при pointer:fine (иначе пропадает курсор).
