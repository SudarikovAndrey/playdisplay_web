# ТЗ: перевод сайта playdisplay на бразильский португальский

Исполнителю: это задание можно выполнять, не читая остальной репозиторий, но
`CLAUDE.md` в корне и `ПРАВИЛА-РАБОТЫ.md` прочитать **обязательно** — там записаны
правила общей папки и грабли, на которые уже наступали.

Номера строк в описях сняты на коммите `83f68fb`. Они сдвинутся от первой же правки —
**ищите по тексту, а не по номеру**. Номер дан как подсказка, где смотреть.

## Задача одной фразой

Сделать третью языковую версию сайта — `/pt/`, бразильский португальский, —
паритетную русской. Включая 3D-сцену на первом экране и мини-игру с полётом,
где русский текст остался даже в английской версии.

## Что уже сделано и трогать не надо

| | |
|---|---|
| Генератор | Готов к третьему языку. `pt` вписан в `LANGS`, вся проза вынесена в `site/data/i18n/prose.json`. Появится `site/data/pt/projects.json` — язык начнёт собираться сам |
| Конвейер перевода | `_tools/i18n_export.py` → `_tools/i18n_import.py` → `_tools/i18n_check.py`. Проверен сквозным прогоном на 2704 строках |
| Батчи | `_i18n/pt/in/`, 25 файлов, ~187 000 знаков. Переводит владелец через ChatGPT |
| Ассистент | Локаль `pt-BR`, промпты переписаны на бразильский вариант |

**Сборка — одна команда:** `python3 build_seo.py`. Ручных ступеней нет.

## Порядок работ

1. **[02-СЦЕНА-И-ИГРА.md](02-СЦЕНА-И-ИГРА.md)** — правки кода сцены и игры.
   Главная и самая объёмная часть. Делается **до** перевода: задача — не перевести,
   а сделать строки переводимыми.
2. **[03-АССИСТЕНТ.md](03-АССИСТЕНТ.md)** — 30 строк ассистента на лендинге, та же работа.
3. Выгрузка: `python3 _tools/i18n_export.py pt`. Всё, что обёрнуто на шагах 1–2,
   приедет в батчи само.
4. Перевод батчей — **не ваша часть**, это делает владелец.
5. Сборка: `python3 _tools/i18n_import.py pt` → `python3 build_seo.py`.
6. **[04-СТРАНИЦЫ-ВНЕ-ГЕНЕРАТОРА.md](04-СТРАНИЦЫ-ВНЕ-ГЕНЕРАТОРА.md)** — `privacy.html`
   и `404.html`: их генератор не делает, нужна ручная вёрстка третьего языка.
7. Карточки превью: `_tools/venv/bin/python _tools/og.py`.
8. **[06-ПРИЁМКА.md](06-ПРИЁМКА.md)** — проверка. Пока она не чиста, `/pt/` не открываем.

Шаги 1–3 можно делать сразу. Шаги 5–7 ждут перевода.

## Границы

**[05-НЕ-ПЕРЕВОДИТЬ.md](05-НЕ-ПЕРЕВОДИТЬ.md) — прочитать до первой правки.**
Там перечислено, что выглядит как русский текст, но переводить его нельзя:
раскладка клавиатуры, комментарии в шейдерах, фильтр мата, коды ОКПД2 и прочее.
Перевод хотя бы одного пункта оттуда ломает работающую вещь.

## Правила репозитория

- Ветка `hybrid-v8`. **Не переключать.**
- `git add` по именам файлов. **Никогда `git add -A`.**
- Коммиты маленькие, сообщения русские, объясняющие «почему», а не «что».
- **Не деплоить.** `./deploy.sh` запускает владелец. `rsync` заливает диск, а не
  коммит: в папке параллельно работают другие чаты, и чужая недоделка уедет вместе
  с вашей правкой.
- `site/landing.css` — собранный файл. Править `_src/landing.css`, дальше
  `python3 build_seo.py` пересоберёт и обновит отпечаток.
- Стиль кода лендинга и сцены: **ES5** (`var`/`function`), комментарии по-русски,
  объясняющие «почему», а не «что».
