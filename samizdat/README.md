# САМИЗДАТ — паспорт направления

Своя издательская линия: прототипы PlayDisplay → площадки → выручка. Цель не «сделать игру», а **научиться проходить весь цикл самостоятельно**: идея → билд → модерация → трафик → деньги на счёт юрлица. Каждый релиз — эксперимент, у которого есть гипотеза и цифры.

Заведено 29.07.2026.

## Структура папки

```
samizdat/
  README.md              ← этот файл: как устроено направление
  PLAN.md                ← дорожная карта и метрики
  JOURNAL.md             ← дневник: что выпустили, что зашло, что нет
  platforms/
    yandex-games.md      ← требования → рабочий чеклист, монетизация, выплаты
    vk.md                ← ВК: что известно, что проверить в кабинете
    compare.md           ← сравнение площадок по порогу входа
  games/
    point-flight/        ← первый кандидат: миниигра из hero-scene
      ASSESSMENT.md      ← вердикт по формату и разрыв до релиза
      store/             ← иконка, обложка, скрины, тексты заявки
      builds/            ← готовые zip-архивы (в git не едут)
```

## Отношения с сайтом

Папка лежит в том же репозитории, но **на сайт не попадает**: сборка `gh-pages` берёт только `site/` (`git archive hybrid-v8 site`). Поэтому `samizdat/` можно держать под версионным контролем без риска утечки в веб.

В git едут документы, тексты заявок и исходники стор-материалов. Не едут: собранные zip-архивы, сырые видео, экспортные PSD — они в `.gitignore`.

**Важно:** билд игры для площадки — это *не* `site/hero-scene.html`. Игра выносится в отдельный самодостаточный билд, потому что у площадки свои требования, которые ломают сайт (SDK Яндекса, запрет внешних ссылок, полноэкранный режим, отсутствие портфолио-слоя). Общий код можно держать общий, но артефакты — отдельные.

## Правила направления

1. **Одна гипотеза на релиз.** Не «выпустим и посмотрим», а «проверяем, что абстрактная графика удерживает казуальную аудиторию» — с заранее названным порогом успеха.
2. **Цифры в JOURNAL.md после каждого релиза.** Через 2 недели после публикации у игры появляется рейтинг — записываем его, ARPDAU, retention, причины отказов модерации.
3. **Отказ модерации — это данные, а не провал.** Пункт отказа заносим в чеклист площадки, чтобы второй раз не наступить.
4. **Убивать быстро.** Если игра три недели держит рейтинг ниже 30 — Яндекс снимет её сам. Не спорим с платформой, идём дальше.
5. **Юрлицо одно на все площадки.** Договоры, реквизиты, акты — в одном месте, налоги платим сами (см. `platforms/yandex-games.md`).
