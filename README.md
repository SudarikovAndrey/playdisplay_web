# PlayDisplay — сайт студии

Сайт студии интерактивного опыта PlayDisplay: **https://playdisplay.com** (и `.ru`, обе
привязаны к одной папке). Одностраничный лендинг с кейс-вьюером, 3D-героем, библиотекой
концепций, Атласом и AI-ассистентом, который разговаривает с посетителем и присылает бриф.

## С чего начать

| Файл | О чём |
|---|---|
| `ПРАВИЛА-РАБОТЫ.md` | **прочитать первым.** Над проектом работают несколько чатов в одной папке, изоляции нет |

## Что где лежит

Весь сайт — в папке `site/`. Она самодостаточна: ссылок за свои пределы не имеет,
и именно она целиком уезжает на хостинг.

```
site/index.html        лендинг-SPA: стили, 15 кейсов, сетка Work, кейс-вьюер,
                       WebGL-переходы FlyGL, роутинг, панель AI-ассистента
site/hero-scene.html   3D-герой на Three.js (облако точек), встраивается iframe'ом
site/data/             контент: projects.json (кейсы), concepts.json, atlas.json
site/api/              бэкенд ассистента на PHP, без зависимостей
site/assets/ videos/   картинки и сжатые ролики
site/work/<slug>/      статические страницы кейсов для поисковиков
```

Генератор SEO-страниц, sitemap и robots — `build_seo.py`. После изменения структуры
или контента кейсов его нужно перегенерить.

## Деплой

```bash
./deploy.sh "что сделали"
```

Скрипт коммитит правки, заливает `site/` на хостинг через `rsync` и пишет отчёт
в `DEPLOY-LOG.md`. Первый запуск сделать холостым: `./deploy.sh --dry-run`.
Подробно, включая разовую настройку — `README-ДЕПЛОЙ.md`.

## Посмотреть локально

```bash
cd site && python3 -m http.server 8000
```

PHP-часть (`site/api/`) так не заработает — простой сервер Python его не исполняет.
Без конфига ассистент и так уходит в демо-режим, для вёрстки этого хватает.
