# Web_Playdisplay

Новый WOW-сайт PLAYDISPLAY — одностраничное портфолио студии интерактивных мультимедиа решений.

## Что внутри

- `index.html` — весь сайт (hero, услуги, 15 проектов, о компании, СМИ, контакты)
- `css/style.css` — стили (тёмная тема, кислотный зелёный, шрифт Unbounded)
- `js/main.js` — эффекты
- `assets/` — папка для локальных медиа

## Эффекты

3D-туннель проектов: скролл двигает камеру сквозь пространство с парящими карточками, сеткой пола/потолка и параллаксом за мышью. RGB-глитч на картинках при наведении. Плюс: прелоадер со счётчиком, кастомный курсор, частицы в hero, объёмный параллакс hero, «расшифровка» заголовков, бегущая строка, счётчики, 3D-наклон карточек, магнитные кнопки, зерно плёнки. На мобильных туннель превращается в обычную сетку.

Картинки проектов подгружаются с playdisplay.com (нужен интернет). Шрифты — Google Fonts, анимации — GSAP (CDN).

## Как посмотреть

Открыть `index.html` в браузере или:

```
python3 -m http.server 8000
```

## Что дальше

- Скачать картинки проектов в `assets/`, чтобы не зависеть от старого сайта
