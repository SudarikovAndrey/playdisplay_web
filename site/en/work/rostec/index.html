Rostec Expo

Holographic catalog

ClientRostec Expo
Timeline6 months
Year2021

The goal

Create the centerpiece exhibit at the entrance to the Rostec Expo pavilion and bring the products of every company in the Rostec group together in one holographic space.

The solution

A holographic installation shaped like the Rostec logo. The transparent screen keeps the hall visible through it, while a control console opens the group’s full product catalog — all inside a single holographic space.

  1. Project concept and design
  2. Engineering, equipment selection and supply
  3. Building the cube structure and manufacturing the control console
  4. Software design and commissioning

The control console

A multifunction device designed in a retrofuturist key. Its working surface carries a set of touch panels for navigating the catalog and driving the interactive content. The base is made of polished galvanized aluminum.

Control console: functional layout

  1. Tactical map window. Activates when the product description includes a matching scenario.
  2. Text prompt window. Holds a short description of the product in one place.
  3. Window showing a scaled-down 3D view of the product.
  4. Navigation bar showing the current path through the catalog.
  5. Button that steps back one level in the catalog.
  6. Window with the current date and time.
  7. Language switch — RU / ENG.
  8. Window that wakes the installation // returns it to the opening idle mode. The two alternate.
  9. Navigation block — shows the status of the animation currently playing and whether that element has audio running.
  10. Volume control for the installation.
  11. 3D joystick for rotating and steering the 3D model. In some scenarios not every axis of rotation is live.
  12. Touchpad pointer. Press and hold to show a cursor on the main holographic screen.
  13. Main interface window. Opens the catalog and lets you pick items from the menu of product descriptions.
