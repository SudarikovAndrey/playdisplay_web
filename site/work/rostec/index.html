Ростех-Экспо

Голографический каталог

ЗаказчикРостех Экспо
Срок реализации6 месяцев
Год2021

Цель проекта

Создать центральный экспонат у входа в павильон «Ростех Экспо» и объединить продукцию всех предприятий холдинга Ростех в едином голографическом пространстве.

Решение

Голографическая инсталляция в форме логотипа Ростех: благодаря прозрачному экрану сохраняется вид зала, а пульт управления открывает доступ к полному каталогу продукции холдинга — в едином голографическом пространстве.

  1. Разработка концепции проекта, дизайн
  2. Инженерные работы, подбор и поставка оборудования
  3. Создание конструкции куба и производство пульта управления
  4. Проектирование программного обеспечения, введение в эксплуатацию

Пульт управления

Многофункциональное устройство, дизайн выполнен в эстетике ретрофутуризма. Рабочая поверхность пульта содержит множество тач-поверхностей, позволяющих осуществлять навигацию по каталогу и управлять интерактивным контентом. Основание выполнено из полированного гальванизированного алюминия.

Функциональная схема пульта управления

  1. Окно демонстрации тактической карты. Активируется при наличии соответствующего сценария в описании продукта.
  2. Текстовое окно-подсказка. Содержит сокращённое описание продукта в одном месте.
  3. Окно вывода уменьшенного продукта в 3D-виде.
  4. Навигационная строка, демонстрирующая адресный путь в каталоге.
  5. Кнопка возврата на один уровень в каталоге.
  6. Окно отображения актуальной даты и времени.
  7. Окно переключения языков — RU / ENG.
  8. Окно активации инсталляции // окно перехода в стартовый режим ожидания. Работает попеременно.
  9. Навигационный блок — отображает статус проигрываемого анимационного блока, а также аудио-активность данного элемента.
  10. Регулировка громкости инсталляции.
  11. 3D-джойстик для вращения // управления 3D-моделью. В некоторых сценариях активны не все оси поворота.
  12. Тачпэд-указка. При нажатии и удержании отображает курсор на основном голографическом экране.
  13. Основное интерфейсное окно. Предоставляет доступ к каталогу, позволяет выбирать пункты из меню с описаниями по продуктам.

Результат

Голографический куб стал центральным презентационным объектом Ростех Экспо и продолжает работать спустя годы после запуска. На нём представляют разработки предприятий корпорации, проводят презентации для партнёров и знакомят делегации с технологическими компетенциями Ростеха.

Инсталляция превратилась из выставочного экспоната в постоянный коммуникационный инструмент: с неё начинаются презентации и важные встречи, а сложные технологии получают зрелищную и понятную форму. Один объект продолжает работать для разных компаний, продуктов и сценариев — контент меняется, а сама система остаётся частью инфраструктуры павильона.
